# Changelog / 变更记录

This file records changes to the **project** — the toolchain, the policy files and the documentation.
It deliberately says nothing about the daily product.

The published list is regenerated by CI on every run (`cron: '17 3 * * *'`) and every regeneration
changes hundreds of hostnames, because upstream feeds change daily. A changelog entry per run would
be noise. What identifies a given list is not a version number but the two header lines inside it:

```
! List revision: <12 hex digits>    # identity of the exact feed content compiled in
! Last modified: <upstream date>    # newest Last-Modified among the feeds that publish one
```

Compare `! List revision:` to know whether two copies of `dist/dns-shield.txt` are the same list.
See `ARCHITECTURE.md` ("Reproducible output") for how both values are derived.
