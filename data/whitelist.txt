# Private whitelist - applied before any blocking layer can take effect.
#
# Two syntaxes, deliberately different:
#   domain.com     release exactly this hostname, keep its subdomains blocked
#   @domain.com    release the whole tree (the hostname and every subdomain)
#
# `@` is blunt: it also releases every tracking subdomain under that name. Use it only where a
# service genuinely moves its endpoints across unpredictable subdomains. data/never-whitelist.txt
# overrides this file, so a tree rule can never resurrect a protected tracker.
#
# Add personal entries at the bottom under PERSONAL. One entry per line; `#` starts a comment.
