# Shared-infrastructure guards.
#
# These are registrable apexes that exist to HOST other people's content. A rule like
# `||azurewebsites.net^` blocks one malicious tenant by blocking every legitimate site on the
# platform, so the apex is released and the subdomains stay blocked (blocking
# `evil.azurewebsites.net` is fine, blocking `azurewebsites.net` is not).
#
# One hostname per line, lowercase, no rules syntax. Exact-apex only: children are unaffected.
# Every entry here was observed as an apex block rule in a real build.
