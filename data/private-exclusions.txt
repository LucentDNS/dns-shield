# Private exclusions - domains we refuse to block outright.
#
# Difference from data/whitelist.txt: a whitelist entry is a request ("release this"), while an
# exclusion is applied to the compiled set before the whitelist stage and is meant for cases
# where the whole class of traffic should never be blocked in the first place. In practice the
# two overlap; use the whitelist for personal entries and this file for project-level policy.
#
# One hostname per line. `#` starts a comment.
